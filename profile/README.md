# FNAV Systems

**Navigate without GNSS.** Passive. Unjammable. Zero RF.

FNAV Systems builds passive navigation for drones, vessels and ground vehicles that operate where GNSS is unavailable, jammed or spoofed. Heading and position come from the stars and the sun: no satellites, no radio emissions, no ground infrastructure.

- **Platforms:** UAV (fixed-wing, multirotor), USV, UGV
- **Integration:** plug-in module; MAVLink output to ArduPilot and PX4; UART / I2C for custom integration
- Ukrainian defence-technology company, BRAVE1 validated
